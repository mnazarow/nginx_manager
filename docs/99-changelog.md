# История версий

Обновление на новую версию: `sudo ./update.sh` из каталога с новой версией (подробно — в главе
[03](03-installation.md)). Перед обновлением делается резервная копия, при ошибке запуска выполняется откат.

## 1.4.0

**Новое**

- **Доступ к сайтам по странам** ([17](17-bans.md#доступ-по-странам)): запретить выбранные страны или разрешить
  только выбранные; исключения по IP, пропуск локальных сетей, ответ 403/444/451. Сети стран панель сама
  выбирает из базы GeoIP (GeoLite2 / DB-IP) и подключает в nginx через `geo` — без сторонних модулей. Проверки
  Let's Encrypt не ограничиваются. Вкладка «Страны» в «Блокировках IP»: состояние базы, сайты с правилами,
  отклонённые запросы по странам и сайтам; диагностика, два новых сценария анализа, метрика Prometheus.
  Обновлённая база подхватывается автоматически.
- **Массовые действия со списком сайтов** ([05](05-sites.md#массовые-действия)): включить, выключить,
  обслуживание, добавить или убрать метку, удалить — для нескольких сайтов сразу; `POST /api/sites/bulk`.
- Названия стран по-русски в аналитике, блокировках и журнале; выбор стран с поиском по названию.
- `update.sh --with-geoip` — добавить поддержку GeoIP при обновлении.

**Исправления и безопасность**

- Проверка значений, попадающих в конфигурацию nginx, усилена по результатам фаззинга всех полей: обратная косая
  черта и `#` в начале значения больше не ломают конфигурацию; хеш пароля Basic Auth проверяется по формату
  (раньше через API можно было дописать строку в файл паролей).
- Хеши паролей Basic Auth больше не отдаются в интерфейс и API: в данных сайта поле пустое, в версиях
  конфигурации и сравнениях вместо хеша — отпечаток.
- Проверка домена для Let's Encrypt (`/api/certs/selftest`) доступна оператору и администратору, а не наблюдателю.
- Ответы, отклонённые блокировками по IP и странам, не считаются нарушениями для автоблокировки и не завышают
  долю ошибок 4xx в анализе (признак `gb` в журнале доступа, учёт кодов отклонённых ответов).
- Добавлены автотесты: фаззинг генератора с проверкой `nginx -t`, обновление базы с версии 1.0.0, доступ по
  странам, массовые действия.

## 1.3.0

**Новое**

- **Тишина оповещений** ([11](11-alerts.md#тишина-на-время-работ)): на время плановых работ — сразу или по
  расписанию, для всех или выбранных правил; срабатывания записываются в историю, уведомления не отправляются;
  значок «тишина» в верхней панели; API для скриптов выкладки.
- **Быстрый поиск (Ctrl+K, ⌘K, /)**: разделы, сайты по названию и домену, вкладки настроек, действия, ответы
  из документации; поиск запросов по IP и коду ответа.
- Нагрузочная проверка сборщика статистики: 3 000 и 10 000 запросов в секунду без отставания (результаты —
  в главе 02).

**Исправления и безопасность**

- Экспорт журнала запросов в CSV защищён от подстановки формул Excel (CSV injection): значения из запросов,
  начинающиеся с `=`, `+`, `-`, `@`, экранируются; добавлен BOM для корректной кириллицы в Excel.
- Таблица нарушителей автоблокировки и завершённые периоды тишины очищаются по сроку хранения.
- Подсказка у карточки закрывается при открытии быстрого поиска.
- Набор правил проверки кода закреплён в `ruff.toml` (не зависит от версии ruff).

## 1.2.0

**Новое**

- **Регулярные отчёты** ([11](11-alerts.md#регулярные-отчёты)): ежедневная или еженедельная сводка в Telegram,
  e-mail, Slack, Discord или webhook — нагрузка и ошибки с изменением к прошлому периоду, время ответа, трафик,
  сайты, проблемы по встроенному анализу, бэкенды, сертификаты, блокировки, журнал ошибок nginx.
  Предпросмотр и отправка кнопкой.
- **Свои пороги анализа** ([18](18-insights.md#свои-пороги)): для 5xx, 4xx, p95, времени бэкенда, кэша, ботов,
  бэкендов, CPU, памяти, диска и нагрузки; действуют и на цвет карточек, и на сценарии.
- **История проблем**: моменты обнаружения и устранения проблем с длительностью (вкладка «История» анализа,
  раздел «События»).
- Интеграционные тесты REST API (вход, CSRF, роли, токены, сайты, блокировки, анализ, отчёты, метрики,
  документация, WebSocket).

**Исправления**

- Копии, которые делают `update.sh` и `nmctl backup` (база, архив кода прежней версии, nginx.conf), больше не
  накапливаются без ограничений: хранится по 5 штук каждого вида (настраивается). Ручные копии из панели не
  удаляются.
- Числа в находках анализа и отчётах выводятся с разделителями разрядов и десятичной запятой.
- Диалоги и подсказки закрываются при переходе на другую страницу.
- Быстрый переход между разделами больше не может показать содержимое предыдущей страницы: если она ещё
  загружала данные, её запоздалый результат отбрасывается.
- `nmctl diag` больше не сообщает ложное «отставание обработки» журнала доступа, когда файл журнала крупнее 50 МБ.

## 1.1.0

**Новое**

- **Встроенный анализ и подсказки** ([18](18-insights.md)): раздел «Анализ и подсказки», карточка на дашборде
  и в аналитике, значок в меню. 79 сценариев: ошибки 5xx с разбором по кодам 502/503/504/500, 4xx по кодам
  (404, 403, 429, 401, 413, 499, 400, 444), задержки (p95, узкое место — бэкенд или клиенты, рост относительно
  прошлых суток), просадки и всплески трафика, доминирующий IP, бэкенды (недоступность, нестабильность,
  медленные проверки, отсутствие резерва и проверок), кэш, боты и сканеры, HTTPS/HSTS/TLS, ёмкость соединений
  nginx, CPU/память/диск/load, сертификаты, конфигурация, сбор данных и все категории журнала ошибок nginx.
  Для каждой находки — объяснение, вероятные причины, шаги, подтверждающие данные и ссылки; скрытие ненужных
  типов подсказок; метрика оповещений `insights_crit`.
- **Подсказки на показателях**: значок «?» на карточках дашборда, аналитики, сервера и бэкендов — что означает
  показатель, как считается, пороги, текущая оценка и что делать; карточки с плохими значениями выделяются.
- **Блокировки IP** ([17](17-bans.md)): ручная блокировка адресов и подсетей (IPv4/IPv6) на срок или бессрочно,
  пакетная блокировка списком, экспорт списка. Список применяется через `geo $nm_banned` без создания версии
  конфигурации и без затрагивания неприменённых правок.
- **Автоблокировка** по журналу доступа: поиск уязвимостей (`.env`, `.git`, phpMyAdmin, SQL-инъекции, обход
  каталогов, Log4Shell…), подбор паролей (401), обращения по IP, массовые 4xx, флуд. Увеличение срока для
  повторных нарушителей, исключения, режим наблюдения («Подозрительные»), метрика оповещений `autobans`.
- Кнопка «Заблокировать IP» в карточке запроса журнала и в топе IP-адресов аналитики.
- **Метрики Prometheus** по адресу `/metrics`: запросы, коды, гистограмма времени ответа, трафик и кэш по сайтам,
  бэкенды, сертификаты, блокировки, ресурсы сервера ([09](09-monitoring.md#метрики-prometheus)). Доступ по
  API-токену или со списка IP.
- **Документация в панели**: поиск по всем главам с подсветкой, оглавление главы с отслеживанием прокрутки,
  ссылки на разделы, переход к соседним главам, печать в PDF, увеличение скриншотов.
- **Справка по странице**: кнопка «?» в верхней панели и клавиша F1 открывают нужный раздел документации
  в боковой панели. Щелчок по значку «i» у любого поля открывает описание именно этого параметра.
- Автономная HTML-версия документации: `python3 tools/build_docs_html.py`.
- Автотесты ядра: `python3 -m pytest -q tests/`.

**Улучшения**

- Сборщик статистики обрабатывает журнал порциями и отдаёт управление между ними: при всплесках трафика и
  дочитывании накопившегося журнала после перезапуска панель и графики не «замирают». Производительность разбора
  с детектором блокировок — около 30 000 строк журнала в секунду на одно ядро.
- Адреса внешних сервисов (Telegram API, webhook, сервис определения внешнего IP) принимают только `http(s)://`.
- Скриншоты и подписи в документации дополнены, схема прохождения запроса исправлена.

**Исправления**

- Права на файлы конфигурации: при установке с ограничивающей umask воркеры nginx не могли прочитать
  собственные страницы ошибок и файлы паролей. Права исправляются автоматически, добавлены проверка
  «Права доступа воркеров nginx» и исправление в один щелчок в Диагностике.
- Категория «Прочее» в журнале ошибок получила описание.

## 1.0.0

Первая версия: графическая настройка сайтов, локаций, бэкендов, HTTPS (Let's Encrypt), кэша, безопасности,
TCP/UDP-потоков и глобальных параметров nginx; безопасное применение с откатом и историей версий; статистика
и аналитика в реальном времени; журналы запросов и ошибок; проверки бэкендов и автопереключение; оповещения;
диагностика с исправлениями; пользователи, роли, 2FA, API-токены, аудит; `nmctl` и REST API; скрипты
установки, обновления и удаления; документация.
